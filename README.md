# Luxury Briefing (Full-Stack Demo)

A luxury intelligence demo: “signals” feed + curated watch windows (auctions/events) with a save-to-vault workflow and light/dark UI themes.

## Stack
- Frontend: React + TypeScript (Vite)
- Backend: FastAPI (Python)
- DB: PostgreSQL + SQLAlchemy
- Containers: Docker + Docker Compose

## Run (Docker)
```bash
docker compose up --build
